Mac의 launchd 서비스를 한눈에 보고 제어합니다. 다른 Mac은 건드리지 않고 상태만 확인합니다.

v0.3.1 · macOS 14+ · Apple Silicon

보여 주는 것과 할 수 있는 것

Mac의 launchd 서비스를 한 창에서 봅니다. 무엇이 실행 중이고 무엇이 대기하거나 실패했는지, 어떤 TCP 포트를 열고 있는지 확인합니다. 다른 Mac을 SSH로 추가하면 함께 볼 수 있습니다.

실행 중이라고 정상은 아닙니다.

launchd가 서비스를 실행하고 있는지와 서비스가 실제로 제 일을 하는지를 따로 다룹니다. 건강 확인 기능은 아직 없으므로 건강 상태는 미확인으로 표시합니다. 실행 중이라는 이유만으로 초록불을 켜지 않습니다.

서비스실행 상태건강 상태
dev.example.api실행 중미확인
com.example.media-sync대기미확인
com.example.thumbnailer실패 · 78미확인

다른 Mac은 읽기 전용으로

다른 Mac을 SSH로 추가하면 이 Mac의 서비스와 나란히 보입니다. 원격 Mac은 보기만 하고 바꾸지 않습니다.

시작, 재시작, 중지

내 LaunchAgent를 창에서 바로 제어합니다. 실행할 때마다 먼저 확인을 받습니다.

CPU, 메모리, 포트

서비스별 CPU·RSS 이력과 수신 대기 중인 TCP 포트를 보여 줍니다. 이력은 설정에서 등록하는 수집기가 있어야 쌓입니다. 측정은 서비스의 대표 프로세스(PID)만 대상이며 자식 프로세스는 포함하지 않습니다.

그룹, 즐겨찾기, 검색

프로젝트별로 서비스를 묶고, 매일 보는 서비스는 즐겨찾기에 넣습니다. label은 입력하는 대로 찾아 줍니다.

메뉴 막대에서도

창을 열지 않고도 주의가 필요한 서비스를 메뉴 막대에서 확인합니다.

어디에도 보내지 않습니다

분석 도구도, 텔레메트리도, 계정도 없습니다. 외부 연결은 직접 설정한 SSH 세션뿐입니다.

유료 launchd GUI를 대신할 무료 오픈소스 앱입니다. 여러 Mac도 함께 볼 수 있습니다.

설치

앱 내려받기

디스크 이미지입니다. 열어서 Launch Board를 응용 프로그램 폴더로 드래그합니다.

Mac용 다운로드

Homebrew로 설치

Ardor Labs tap에서 설치합니다. 업데이트는 brew upgrade로 합니다.

brew install ardorframes-labs/tap/launch-board

하지 않는 일

Launch Board는 바꾸기보다 보는 데 집중합니다. 아래 제한은 의도한 것입니다.

  • 시스템 서비스는 읽기만제어할 수 있는 것은 내 LaunchAgent뿐입니다. 시스템 서비스는 시작·중지·편집하지 않으며, LaunchDaemon은 정의만 읽고 실행 상태를 미확인으로 표시합니다.
  • 원격 제어 없음다른 Mac은 조회 전용입니다. 그 Mac의 서비스를 바꾸려면 해당 Mac에서 직접 해야 합니다.
  • plist 삭제 없음Launch Board는 plist 파일을 지우지 않습니다. 서비스를 없앨지는 사용자가 정합니다.

자주 묻는 질문

App Store에 없는 이유

App Store 앱은 샌드박스 안에서 실행되는데, 샌드박스에서는 launchctl로 서비스를 제어할 수 없습니다. 그래서 GitHub과 Homebrew로 직접 배포합니다.

필요한 권한

내 서비스를 읽는 데는 특별한 권한이 필요 없습니다. 다른 Mac을 추가할 때는 이미 가진 SSH 접근 권한을 그대로 씁니다. 시작, 재시작, 중지 전에는 항상 먼저 묻습니다.

제거 방법

수집기를 등록했다면 먼저 설정에서 해제합니다. 그다음 Launch Board를 종료하고 휴지통으로 옮깁니다. Homebrew로 설치했다면 brew uninstall launch-board를 실행합니다.

데이터 수집 여부

수집하지 않습니다. 분석 도구, 충돌 보고, 계정이 모두 없습니다. CPU와 메모리 이력은 내 Mac에만 남습니다.
